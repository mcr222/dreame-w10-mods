Dreame W10 (P2027): Root Checklist

UART root without the breakout PCB → DustBuilder rooted firmware → Valetudo.
W10 = UART method, no secure boot, Valetudo build armv7-lowmem. Full explanations: rooting-guide.md. The official Valetudo Dreame guide is the source of truth.

Your ticks are saved automatically in this browser.
Placeholders: <SERIAL> = serial from the sticker under the dustbin (capitals) · <XXXX> = end of the robot hotspot name dreame-vacuum-p2027_miap<XXXX> · IP:PORT = address printed by the file server (starts with 192.168.5.) · <robot-ip> = robot on your home network.
Safety rules (always)
  • 🔴 Red (VBUS 5V) never goes to the USB-TTL adapter or the laptop. The robot's USB wires never go to the laptop.
  • Robot col 8 (BOOT_SEL), adapter 3V3 and adapter 5V stay empty. The adapter must use 3.3V signals.
  • Wire only with the robot OFF. Unplug in this order: 5V first, ground last.
  • Never power off or undock the robot while the firmware is installing.

A · Preparation

1Build the rooted firmware on DustBuilder for your serial (preinstalled tools, patch DNS for Valetudo, manual installer). Download dreame.vacuum.p2027_fw.tar.gz and the SSH key zip (its password is in the DustBuilder email). The firmware's md5 matches the one DustBuilder gives you.
2Work out the root password from the serial: 
echo -n "<SERIAL>" | md5sum | base64
Same password as on the DustBuilder confirmation.
3While still online, download valetudo-helper-httpbridge into a folder, and valetudo-armv7-lowmem plus a copy of the firmware into its www/ subfolder.
4Parts: USB-TTL adapter (3.3V), jumper wires for 2.0mm holes, multimeter, USB stick, USB cable cut to get a female socket.

B · Serial connection (UART)

5Open the debug port: dustbin out, rubber flap open → 16-pin 2.0mm socket (see the pin map in the appendix).
6Recommended: adapter test: brown (TXD) vs black (GND). ≈ 3.3V. 5V means stop and switch the adapter's jumper.
7Robot OFF. Connect the 3 UART wires:
adapter GND / black ↔ black → bottom col 6
adapter RXD / white ↔ orange → top col 6 (robot TX)
adapter TXD / brown ↔ yellow → top col 7 (robot RX)
8Laptop: install the tools and open a logged serial session (Ctrl+A Ctrl+X quits picocom · Ctrl+B D leaves it running · tmux attach -t w10 gets back). Your user must be in dialout. 
sudo apt install picocom tmux
tmux new -s w10 'picocom -b 115200 --logfile ~/w10_serial.log /dev/ttyUSB0'
9Turn the robot on (hold POWER 3s). Readable boot log, chpasswd: password for 'root' changed, Wi-Fi hotspot dreame-vacuum-p2027_miap<XXXX> enabled.

C · USB stick & root login

10USB stick: MBR partition table with one FAT32 partition (no files needed). Check with lsblk -f. sdX1 vfat FAT32. A table with no partition won't trigger. Fallback: the known-good image dreame_uart_root.img from valetudo.cloud.
11Test the cut USB socket cable (red/white/green/black) with the meter. Contact order red, white, green, black · red ↔ black: no short. A socket shell not connected to black is normal on cheap cables.
12Robot OFF. Wire the socket:
red → col 1 · white → col 2 · green → col 3
socket black → blue col 5 + blue scrap col 4 (USB-ID bridge to GND → robot becomes USB host). Insulate the joints.
13Power on, wait for password for 'root' changed, plug the stick into the socket → p2027_release login: → log in as root with the password from step 2. [root@p2027_release:~]# on the stock firmware.
14Check free space: 
df -h /tmp /data
/tmp ≈ 110 MB free (RAM) · /data ≈ 120 MB free. Enough for the ~66 MB firmware and ~34 MB Valetudo.

D · Backup & file transfer (laptop offline)

Joining the robot's hotspot means no internet until step 21 if your laptop has only one Wi-Fi card. Print this page or keep it open locally.
15Laptop → robot hotspot. Not listed? Hold the robot's two outer buttons until it talks. 
nmcli dev wifi connect "dreame-vacuum-p2027_miap<XXXX>"
16Start the file server and write down the IP:PORT it prints: 
./valetudo-helper-httpbridge-amd64
An address starting with 192.168.5.
17Robot: backup → upload → free RAM: 
tar cvf /tmp/backup.tar /mnt/private/ /mnt/misc/ /etc/OTA_Key_pub.pem /etc/publickey.pem
curl -X POST http://IP:PORT/upload -F 'file=@/tmp/backup.tar'
rm /tmp/backup.tar
Successfully uploaded; ≈ 45 KB backup.tar in www/uploads/ with identity (sn, did, key, mac, cpuid), LiDAR calibration, stats, public keys.
18Robot: firmware → /tmp, check: 
cd /tmp
wget http://IP:PORT/dreame.vacuum.p2027_fw.tar.gz
md5sum /tmp/dreame.vacuum.p2027_fw.tar.gz
Same md5 as DustBuilder's. If not: delete and download again.
19Robot: Valetudo → /data, check: 
wget http://IP:PORT/valetudo-armv7-lowmem -O /data/valetudo
chmod +x /data/valetudo
ls -l /data/valetudo
Same size as the file on the laptop, executable.
20Ctrl+C on the file server, laptop back to your home Wi-Fi.
21Copy the backup off the laptop (another stick or private cloud storage). Keep it private: it's your robot's identity.

E · Install the rooted firmware

22Robot: unpack, free RAM, list: 
cd /tmp
tar -xzvf dreame.vacuum.p2027_fw.tar.gz
rm dreame.vacuum.p2027_fw.tar.gz
ls -l
rootfs.img (~29 MB) · boot.img · mcu.bin · UIMA/UIMB.bin · install.sh · firmware.md5sum
23Start the install with a 5-minute delay (the installer checks model, size and md5 before writing): 
sleep 300 && ./install.sh
24Unplug the wires from the robot, 5V first and ground last, with the adapter still in the laptop:
red → white → green → bridge → blue → orange → yellow → black last
25Close the flap, put the dustbin back, dock the robot. Then unplug the adapter and the stick.
26Wait about 15 min from step 23 without touching it: update voice/beeps → quiet while writing → reboot (startup sound) → charging on the dock.
No reboot at all? The countdown may have been interrupted when unplugging. That's harmless (nothing written); run steps 22–25 again.
27Reconnect only the 3 UART wires (step 7). No USB stick needed any more: the rooted firmware keeps a login on the serial port.
28Restart the serial session (step 8), press Enter → log in as root (same password).
29Check the root: the banner must show
built with dustbuilder (https://builder.dontvacuum.me) <build date> <build number>
→ rooted ✅

F · Valetudo

30Robot shell. Valetudo is already in /data from step 19; turn on the autostart hook and reboot: 
ls -l /data/valetudo
cp /misc/_root_postboot.sh.tpl /data/_root_postboot.sh
reboot
31Laptop → dreame-vacuum-p2027_miap<XXXX> → open http://192.168.5.1 (Valetudo) → set up your home Wi-Fi → laptop back to home Wi-Fi.
32Find the robot's new IP on the home network (router's DHCP list; a reservation keeps it fixed) → open Valetudo at http://<robot-ip>. ps | grep [v]aletudo on the robot shows /data/valetudo.
33SSH (no more wires needed). Unzip the DustBuilder key zip (password in the DustBuilder email): 
ssh -i <jobid>.id_rsa root@<robot-ip>
